# Salary-price-prediction-using-ensemble-learning-
Salary Prediction Using Ensemble Learning predicts employee salaries from factors such as education, experience, job role, skills, age, and location. It applies ensemble algorithms including Random Forest, Gradient Boosting, AdaBoost, and Extra Trees to improve accuracy, compare performance, and identify the best prediction model. for recruitment..
